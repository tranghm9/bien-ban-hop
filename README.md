# Biên Bản Họp

Ứng dụng web cá nhân chạy trên iPhone: ghi âm cuộc họp, chuyển thành chữ và phân biệt người nói (AssemblyAI), tạo biên bản và xuất file Excel.

- Không chứa dữ liệu hay khoá API nào. Khoá API và biên bản được mã hoá bằng mã PIN, chỉ lưu trên điện thoại người dùng.
- Ghi âm gửi thẳng từ điện thoại đến AssemblyAI, không qua máy chủ trung gian.
